Tessera 1.0.1 speaks English. The interface now follows your Windows display language: English or Simplified Chinese, and English for every other language.

## Download

| File | What it is |
|---|---|
| `tessera-v1.0.1-windows-x64.exe` | The app for most PCs (Intel or AMD). A single portable file: no installer, just double-click it |
| `tessera-v1.0.1-windows-arm64.exe` | The app for Windows on Arm PCs (Snapdragon and other Arm processors) |
| `tessera-cli-v1.0.1-windows-x64.exe` | Command-line tool for scanning, benchmarking and watching live updates |
| `tessera-cli-v1.0.1-windows-arm64.exe` | The command-line tool for Windows on Arm |
| `SHA256SUMS.txt` | SHA-256 checksums of the files above |

Not sure which one? Settings › System › About shows the "System type": "x64-based processor" takes the x64 file, "ARM-based processor" the arm64 one.

Requires 64-bit Windows 10 or 11 and the WebView2 runtime (built into Windows 11; on Windows 10 it usually came with Edge). The app is not code-signed yet; when SmartScreen says "Windows protected your PC", click "More info", then "Run anyway".

## What's new

- **English interface.** When it starts, Tessera reads your "Preferred languages" list (Settings › Time & language › Language & region) and uses the first language it has a translation for. Today that is English or Simplified Chinese; Traditional Chinese and every other language show English. There is no language setting in the app.
- Dates and numbers follow the same language. English uses your own English region's formats (for example `03/11/2026` for en-GB and `11/3/2026` for en-US). The Chinese interface looks exactly as before.
- Everything the app explains in words is translated too: why a folder can't be deleted, hints on system files such as `hiberfil.sys`, drive names and error messages.
- In English, the two delete buttons in the details pane stack when their labels don't fit side by side.

## Known limitations

- No installer and no code signing yet.
- Only English and Simplified Chinese so far.
- After a scan without admin rights, locations the app may not read (such as `System Volume Information`) are not shown separately, so the blocks add up to a little less than the used space. Scanning as administrator doesn't have this problem.
- Only the computer's fixed and removable drives are listed; network drives are not supported yet.
