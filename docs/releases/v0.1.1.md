Tessera 0.1.1 is a small fix release.

## Fixes

- The "running without admin rights" hint (以普通权限运行) at the bottom of the drive picker is now a Fluent info bar. Its text and button use the normal text color instead of the whole block being gray, the icon uses the accent color, and the button has a shield icon to show that it needs admin rights.
- All standard buttons now explicitly use the normal text color, so they no longer turn gray when they sit in an area with gray text.

## Download

| File | What it is |
|---|---|
| `Tessera-v0.1.1-windows-x64.exe` | The app. A single portable file: no installer, just double-click it |
| `tessera-cli-v0.1.1-windows-x64.exe` | Command-line tool |
| `SHA256SUMS.txt` | SHA-256 checksums of the two files above |

The system requirements are the same as for 0.1.0: 64-bit Windows 10 or 11 and the WebView2 runtime. The app is not code-signed yet; when SmartScreen warns you, click "More info", then "Run anyway".
