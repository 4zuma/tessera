Tessera 0.1.1 是一个小修正版本。

## 修正

- 选择磁盘页面底部“以普通权限运行”的提示改成了 Fluent 的信息栏样式：文字和按钮都用正常的文字颜色，不再整块发灰，图标用强调色，按钮上加了表示需要管理员权限的盾牌图标。
- 所有标准按钮的文字都明确使用正常文字颜色，不会再因为放在灰色文字的区域里而跟着变灰。

## 下载

| 文件 | 说明 |
|---|---|
| `Tessera-v0.1.1-windows-x64.exe` | 图形界面程序。单个文件，不用安装，双击就能运行 |
| `tessera-cli-v0.1.1-windows-x64.exe` | 命令行工具 |
| `SHA256SUMS.txt` | 上面两个文件的 SHA-256 校验值 |

系统要求和 0.1.0 一样：64 位 Windows 10 或 11，以及 WebView2 运行时。程序还没有代码签名，SmartScreen 提示时点“更多信息”，再点“仍要运行”。

---

**English:** A small fix release. The "running without admin rights" hint on the drive picker is now a Fluent info bar with normal-contrast text and button instead of all-grey text, and standard buttons always use the primary text colour.
