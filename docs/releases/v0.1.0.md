Tessera 的第一个预览版：扫描一个磁盘，用矩形树图看清空间都去了哪里，再把不需要的东西删掉。

## 下载

| 文件 | 说明 |
|---|---|
| `Tessera-v0.1.0-windows-x64.exe` | 图形界面程序。单个文件，不用安装，双击就能运行 |
| `tessera-cli-v0.1.0-windows-x64.exe` | 命令行工具，可以扫描、跑基准测试、观察实时更新 |
| `SHA256SUMS.txt` | 上面两个文件的 SHA-256 校验值 |

需要 64 位的 Windows 10 或 11，以及 WebView2 运行时（Windows 11 自带，Windows 10 一般也已经通过 Edge 装好了）。

程序还没有代码签名，第一次运行时 SmartScreen 可能会提示“Windows 已保护你的电脑”。点“更多信息”，再点“仍要运行”就可以了。

## 这个版本能做什么

**扫描**
- 普通权限下用多线程逐个目录扫描。在我们的测试机上，约 330 万个文件和文件夹的系统盘用时 10 到 20 秒。
- 以管理员身份运行时直接读取 NTFS 的主文件表（MFT），通常只要几秒。没有管理员权限时，点工具栏上的盾牌按钮可以以管理员身份重启。
- 扫描过程中图会实时长出来，“尚未扫描”的那一块随之缩小。
- 扫描完成后会继续跟踪磁盘上的变化（管理员模式下用 USN 日志），图会自动更新，空闲时几乎不占 CPU。

**矩形树图**
- 双击放大到文件夹，返回时有平滑的缩放动画；没有变化时不重绘。
- 只有一个子文件夹的路径会折叠成一块，大量小文件会合并显示，太小写不下名字的块不显示文字。
- 按文件类型着色（视频、图片、压缩包、磁盘镜像、开发文件等），可以按类型筛选。
- 可以在“占用空间”和“实际大小”之间切换。

**选择和删除**
- 单击选择，Ctrl+单击多选，Shift+单击连选，方向键在相邻的块之间移动。
- 删除到回收站，可以撤销；也可以永久删除，会先弹出确认对话框。
- 可以直接清空回收站。系统关键位置受保护，被占用的文件会说明原因。
- 右键可以在资源管理器中显示。

**外观**
- Fluent 风格，Mica 背景，跟随系统的强调色以及浅色、深色模式。

## 已知限制

- 没有安装程序，没有代码签名，只有 x64 版本。
- 以普通权限扫描完成后，没有权限读取的位置（比如 `System Volume Information`）不会单独显示，所以各块加起来会比已用空间少一些。以管理员身份扫描没有这个问题。
- 只列出本机的固定磁盘和可移动磁盘，暂不支持网络驱动器。

---

**English:** First preview of Tessera, a fast disk-space treemap for Windows. Download `Tessera-v0.1.0-windows-x64.exe` (portable, no installer; needs Windows 10/11 x64 with WebView2). The build is unsigned, so SmartScreen may ask you to confirm with "More info › Run anyway". Scans run without admin rights (multithreaded directory walk) or, elevated, straight from the NTFS master file table; the map grows live during the scan and keeps itself up to date afterwards. Delete to the Recycle Bin with undo, or permanently after a confirmation dialog. The UI is in Chinese for now.
