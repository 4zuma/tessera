The first preview of Tessera: scan a drive, see in a treemap where the space went, and delete what you don't need.

## Download

| File | What it is |
|---|---|
| `Tessera-v0.1.0-windows-x64.exe` | The app. A single portable file: no installer, just double-click it |
| `tessera-cli-v0.1.0-windows-x64.exe` | Command-line tool for scanning, benchmarking and watching live updates |
| `SHA256SUMS.txt` | SHA-256 checksums of the two files above |

Requires 64-bit Windows 10 or 11 and the WebView2 runtime (built into Windows 11; on Windows 10 it usually came with Edge).

The app is not code-signed yet, so on first run SmartScreen may say "Windows protected your PC". Click "More info", then "Run anyway".

## What this version does

**Scanning**
- Without admin rights it walks the drive folder by folder on several threads. On our test machine a system drive with about 3.3 million files and folders takes 10 to 20 seconds.
- Run as administrator, it reads the NTFS master file table (MFT) directly, which usually takes a few seconds. Without admin rights, the shield button on the toolbar restarts the app as administrator.
- The map grows live while the scan runs, and the "not scanned yet" block shrinks as it goes.
- After the scan it keeps tracking changes on the drive (through the USN journal when running as administrator) and updates the map by itself, using almost no CPU while idle.

**Treemap**
- Double-click a folder to zoom into it; going back zooms out with a smooth animation. Nothing is redrawn while nothing changes.
- A chain of folders that each hold just one subfolder collapses into a single block, lots of small files are grouped together, and blocks too small for a name show no label.
- Blocks are colored by file type (video, images, archives, disk images, developer files and more), and you can filter by type.
- Switch between size on disk (占用空间) and logical size (实际大小).

**Selecting and deleting**
- Click to select, Ctrl+click to add to the selection, Shift+click to select a range, and use the arrow keys to move between neighboring blocks.
- Delete to the Recycle Bin with undo, or delete permanently after a confirmation dialog.
- Empty the Recycle Bin from the app. Critical system locations are protected, and files that are in use tell you why they can't be deleted.
- Right-click to show an item in File Explorer.

**Look**
- Fluent style with a Mica background, following the system accent color and light or dark mode.

## Known limitations

- No installer, no code signing, x64 only.
- The interface is in Chinese for now.
- After a scan without admin rights, locations the app may not read (such as `System Volume Information`) are not shown separately, so the blocks add up to a little less than the used space. Scanning as administrator doesn't have this problem.
- Only the computer's fixed and removable drives are listed; network drives are not supported yet.
