Tessera 1.0 is the first stable release: scan a drive, see in a treemap where the space went, and delete what you don't need. It brings together everything from the 0.x previews; the app works the same as in 0.3.2.

## Download

| File | What it is |
|---|---|
| `tessera-v1.0.0-windows-x64.exe` | The app for most PCs (Intel or AMD). A single portable file: no installer, just double-click it |
| `tessera-v1.0.0-windows-arm64.exe` | The app for Windows on Arm PCs (Snapdragon and other Arm processors) |
| `tessera-cli-v1.0.0-windows-x64.exe` | Command-line tool for scanning, benchmarking and watching live updates |
| `tessera-cli-v1.0.0-windows-arm64.exe` | The command-line tool for Windows on Arm |
| `SHA256SUMS.txt` | SHA-256 checksums of the files above |

Not sure which one? Settings › System › About shows the "System type": "x64-based processor" takes the x64 file, "ARM-based processor" the arm64 one.

Requires 64-bit Windows 10 or 11 and the WebView2 runtime (built into Windows 11; on Windows 10 it usually came with Edge). The app is not code-signed yet; when SmartScreen says "Windows protected your PC", click "More info", then "Run anyway".

## What Tessera does

**Scanning**
- Without admin rights it walks the drive on several threads. On our test machine a system drive with about 3.3 million files and folders takes 10 to 20 seconds.
- Run as administrator, it reads the NTFS master file table (MFT) directly, which usually takes a few seconds. The shield button on the toolbar restarts the app as administrator.
- The map grows live while the scan runs.
- After the scan it keeps following changes on the drive (through the USN journal when running as administrator) and updates the map by itself, using almost no CPU while idle. Files with several names (hard links) are counted once, during the scan and in these updates.

**Treemap**
- Double-click a folder to zoom into it; going back zooms out with a smooth animation.
- A folder opens only when there is room for its name and for a few named blocks inside it; zooming in reveals deeper levels. Folders that stay closed are lightly tinted by the file type that fills most of them.
- Blocks are colored by file type (video, images, archives, disk images, developer files and more), and you can filter by type.
- Switch between size on disk and logical size.
- Stays at 60 fps in a maximized or 4K window: folders and files are drawn with WebGL, and hovering repaints only what changed. Nothing is redrawn while nothing changes.

**Selecting and deleting**
- Click to select, Ctrl+click to add to the selection, Shift+click to select a range, and use the arrow keys to move between neighboring blocks.
- Delete to the Recycle Bin with undo, or delete permanently after a confirmation dialog. You can also empty the Recycle Bin from the app.
- Critical system locations are protected: the details pane says why a folder can't be deleted, and files that are in use say why too.
- Right-click opens Tessera's own short menu: zoom in, show in File Explorer, copy the path, or delete.

**Look**
- Fluent style with a Mica background, following the system accent color and light or dark mode. The details pane slides in and out with Windows 11's own timing.

## Since 0.3.2

- Nothing changes in the app.
- New: native builds for Windows on Arm (arm64), made from the same 1.0.0 code and added to this release after it was first published.
- New versions are now published automatically when the version change is merged, so releases no longer wait for a manual step.

## Known limitations

- No installer and no code signing yet.
- The interface is in Chinese for now.
- After a scan without admin rights, locations the app may not read (such as `System Volume Information`) are not shown separately, so the blocks add up to a little less than the used space. Scanning as administrator doesn't have this problem.
- Only the computer's fixed and removable drives are listed; network drives are not supported yet.
