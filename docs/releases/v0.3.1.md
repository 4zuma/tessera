Tessera 0.3.1 是一个小修正版本，修正扫描完成后实时更新时硬链接文件的大小统计。

## 修正

一个文件可以有好几个名字（硬链接），比如 Windows 组件存储 WinSxS，或者 pnpm 把包链接到各个项目的 `node_modules` 里。扫描本来就只把这样的文件算一次，但扫描完以后实时跟踪磁盘变化时没有保持这一点：

- 新建一个硬链接时，文件的大小会被再算一次，总量虚高。
- 删掉正在计算大小的那个名字后，文件的大小会从图里消失，其他名字仍显示为 0。
- 通过另一个名字修改文件时，显示的大小不更新。
- 扫描完成后新出现或重新扫描的文件夹里，如果有文件在别处也有名字，会被重复计算。
- 以管理员身份运行时，新建的硬链接不会出现在图里，删掉的硬链接会一直留在图里。

现在不管怎样新建、改名或删除，同一个文件的大小只算一次，删掉其中一个名字后，大小会转到剩下的名字上。只在本地 NTFS 磁盘上跟踪，其他文件系统不受影响。

---

**English:** A small fix release for live updates after a scan. Files with several names (hard links, e.g. in WinSxS or a pnpm store) were already counted once by the scan, but the change watcher could count a new link twice, lose the size when the counting name was deleted, miss writes made through another name, and (when running as administrator) not add or remove link names at all. Each such file now counts exactly once, and its size moves to a remaining name when one is deleted. Tracking is limited to local NTFS drives.
