Tessera 0.2.0 changes when folders open in the treemap, so deep paths no longer fill the screen with empty folder frames nested inside each other.

## What's new

**Folders open only when it's worth it**
- A folder opens only when it meets all three conditions: it has room for a header (so an open folder always shows its name); it is at least about 80 × 80 pixels, enough for a few named blocks inside; and it takes up more than 0.25% of the current view.
- The 0.25% is measured against the current view, not the whole drive, so deeper levels still open after you double-click to zoom in.
- In a very large window or on a 4K screen, no more levels open than in a normal window: the map is clearer and there are far fewer blocks to draw.
- A folder that stays closed is shown as one block with its name and size; double-click it to zoom in.

**Closed folders are tinted by what they hold**
- A closed folder gets a light tint in the color of the file type that takes up most of its space. It keeps the folder border and the normal text color, so it doesn't look like a file.
- The tooltip says what the folder mostly holds, for example "文件夹 · 多为视频" (folder · mostly video).
- When you filter by type, folders whose main type matches are highlighted too.

**Faster**
- Working out a file's type from its extension is about 5× faster, and the per-type legend is faster with it.
- Repeated layouts when zooming in, zooming out or refreshing take almost no time.
