Tessera 0.2.0 改了树图里文件夹什么时候展开，路径很深的时候不再满屏都是一层套一层的空文件夹框。

## 新变化

**文件夹只在值得展开时才展开**
- 一个文件夹要同时满足三个条件才会展开：放得下标题栏（所以展开的文件夹一定有名字）；至少约 80 × 80 像素，里面放得下几个有名字的块；占当前视图 0.25% 以上。
- 0.25% 是相对当前视图算的，不是相对整个分区，所以双击放大以后，更深的层级照样会展开。
- 窗口很大或者 4K 屏幕时，展开的层数不会比普通窗口多，图更清楚，要画的块也少很多。
- 没有展开的文件夹显示为一整块，带名字和大小，双击可以放大进去。

**没展开的文件夹按内容着色**
- 没展开的文件夹会带一层淡淡的颜色，颜色取自里面占空间最多的文件类型。它们仍然保留文件夹的边框和普通文字颜色，不会被看成文件。
- 提示里会写明文件夹里主要是什么，比如“文件夹 · 多为视频”。
- 按类型筛选时，主要类型相同的文件夹也会一起突出显示。

**更快**
- 按扩展名判断文件类型的速度快了大约 5 倍，按类型统计的图例也跟着变快。
- 放大、缩小、刷新时的重复布局几乎不花时间。

**English:** Folders in the treemap now open only when that adds something: the folder must fit a header band, be about 80 × 80 px or larger, and take more than 0.25 % of the current view (so zooming in still reveals deeper levels, and a 4K window no longer opens more levels than a normal one). Closed folders are lightly tinted by the file type that fills most of them, and the tooltip says so. File-type classification is about 5× faster. Download file names are now all lowercase.
