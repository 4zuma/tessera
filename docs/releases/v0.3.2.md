Tessera 0.3.2 is a maintenance release. It updates two libraries that the app uses through Tauri to versions without known security issues. Nothing changes in how the app looks or works.

## Fixes

- **`time` 0.3.45 → 0.3.47** ([RUSTSEC-2026-0009](https://rustsec.org/advisories/RUSTSEC-2026-0009.html)): parsing a specially crafted RFC 2822 date could exhaust the stack and crash the program.
- **`serde_with` 3.17.0 → 3.21.0** ([GHSA-7gcf-g7xr-8hxj](https://github.com/advisories/GHSA-7gcf-g7xr-8hxj)): serializing an empty entry with `KeyValueMap` could panic.

Tessera never used either of these: it doesn't parse RFC 2822 dates, and nothing in it uses `KeyValueMap`. The update keeps versions with known issues out of the published builds.
