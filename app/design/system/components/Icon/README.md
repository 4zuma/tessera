A line icon by `name`, `size` px (default 16), in `currentColor`: a 24-unit grid, 1.5 stroke, round caps and joins, in the spirit of Fluent System Icons.

Names: drive, folder, file, refresh, stop, up, back, trash, purge, sweep, copy, reveal, search, zoom, lock, undo, chev, chevDown, check, cloud, warn, info, shield, pane, dismiss, more, download. Use 16 px in buttons and menus, 12 px in breadcrumbs. No emoji, no filled icons; an icon that is not here is drawn in the same style and added to `app/src/lib/icons.ts`.
