Tessera's context menu, on acrylic: a header with the name and size, then Show in File Explorer, Copy path, Move to Recycle Bin, Delete permanently (in `critical`) and "Show more options", which opens Windows' own menu.

Rows are 32 px with an icon, label and shortcut (`caption`, `text-2`); disabled rows explain why in a note row with a lock. It opens where the pointer is, so this preview shows it over a `Treemap` with `scenario="menu"`.
