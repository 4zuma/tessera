The command bar under the title bar: drive menu, Up, the breadcrumb path, Rescan (Stop while scanning), the "Size on disk | Size" segmented control, the admin shield, the details-pane toggle and the ⋯ menu (version, "Clear all settings").

The segmented control is part of it: a sunken `ctl-alt` track, the chosen segment raised like a button with a 16 px `accent` pill under its label. `paneOpen` shows the pane toggle pressed (default true); `search` puts the search box here, only for windows without the custom title bar (Windows 10).
