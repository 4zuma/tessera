The search box: a Fluent text box with a search icon, a result count ("2 items · 60.1 GB") and a clear button.

It filters the map as you type: `*.vhdx` or `.vhdx` for extensions, `>1GB` or `<=10MB` for sizes, plain or quoted words for names, all combined. Width comes from its slot (the title bar gives it about 400 px). Set `scenario="search"` and `query` to show it with a query.
