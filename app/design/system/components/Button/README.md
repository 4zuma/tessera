A Fluent button: 32 px tall, `r-ctl` corners, a `ctl` fill with a `ctl-stroke` border and a darker `ctl-stroke-2` bottom edge.

`variant="accent"` is for the one main action of a view (Undo in a toast, Restart as administrator); `variant="danger"` only for permanent deletion. Text is a verb phrase in sentence case; `icon` goes before it. In markup it is `<button class="btn">`, `class="btn accent"`, `class="btn danger"`. Hover and press change the fill only.
