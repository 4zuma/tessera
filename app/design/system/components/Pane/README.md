The details pane: a 300 px column of cards. The details card names what is under the pointer or selected (size, share bar, size on disk and logical size, modified date, path); the "By type | By age" switch colours the map and breaks the view down by file category or by how long ago things changed (age bands the user can edit); the selection card holds "Move to Recycle Bin" and "Delete permanently" and, with nothing selected, the how-to hint.

Give it a slot as tall as the window's middle row. It shows what the map next to it is doing, so this preview puts a `Treemap` beside it with `scenario="selected"`.
